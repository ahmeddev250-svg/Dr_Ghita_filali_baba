# Cabinet Dr. Ghita Filali Baba — Dermatologie, Médecine Esthétique & Lasers (Rabat)

Application web bilingue (Français / Arabe avec support complet RTL) dédiée au cabinet médical du **Dr. Ghita Filali Baba**, Dermatologue - Vénérologue à Rabat.

## Installation & Démarrage

```bash
npm install
npm run dev
```

Pour tester sur mobile sur le même réseau local :

```bash
npm run dev -- --host
```

Pour générer la version de production :

```bash
npm run build
```
